# 21 Days Master Your Focus

## Project Description
21 Days Master Your Focus is a productivity website designed to help users improve their focus, build good habits and manage daily activities through a 21-day plan.

## Project Objectives
- Improve concentration and focus.
- Develop productive daily habits.
- Encourage consistency and discipline.
- Track progress over 21 days.

## Features
- 21-day focus improvement plan.
- Daily activities and tasks.
- User-friendly interface.
- Progress tracking.

## Technologies Used
- HTML
- CSS
- JavaScript

## AI Tools Used
- ChatGPT
- Cursor AI

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Start using the 21-day focus plan.
